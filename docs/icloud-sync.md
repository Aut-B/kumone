# iCloud 同步

同步通过共享目录保存设备会话与通用偏好。首次使用由系统文件选择器授予目录访问权；在该目录下创建或读取 `Kumone`。这种方式支持不同签名团队及重签名侧载版本，无需共享官方 iCloud entitlement 或 Keychain access group。已有同步目录由 `repository.json` 识别，重命名后仍可读取。

## 领域与存储

`SyncRecord<Payload>` 提供格式版本、逻辑修订、设备、更新时间及删除标记；账号只存在于对应领域载荷中，格式版本只在解码边界验证。`SyncRepository` 负责授权书签、文件协调、文件变更通知、通用读写缓存和冲突版本读取。`PlaybackSyncStore` 集中管理播放快照的拆分、关联、复用与维护，借用同一 repository actor 的隔离执行，无额外任务或 actor；连接结束时一起清空状态。每个设备仅写入 `Devices/<deviceID>/`，包含 `playback.json`、`preferences.json`、`login.json` 及 `Queues/<queueRevision>.json`。新增领域时定义 payload、校验与应用规则，再接入 repository；播放器及设置不依赖文件传输细节。

设备 ID 保存到不参与云端同步、设备迁移的本机 Keychain。相同 Keychain 访问范围下重装复用 ID，过滤本机记录；设备名称只用于展示，同名设备保持独立。Keychain 读取或写入失败时停止连接并显示错误，避免临时生成新 ID 发布重复设备。系统清除 Keychain 或侧载改变签名团队、访问组时可能产生新身份，不能仅凭名称判断两条记录来自同一物理设备。

同步允许弱一致：文件通知和定时刷新推动合并，离线修改在恢复连接后传播，重复读取和不同合并顺序得到相同结果；未变化的偏好不重复持久化。没有逐次变更确认、实时设备心跳或跨设备锁，最终传播仍依赖 iCloud 可用及设备再次运行应用。

三个领域独立处理读写失败，保留各自成功发布的检查点；失败领域在下一轮重试，其余领域仍可读取、发布或撤回。偏好合并在完整校验后提交，损坏的远端值不会污染本机偏好。播放读取失败保留上次会话列表，登录目录整体不可读时撤下账号入口；错误通过同步状态呈现。

本机离散事件只比较、发布本机变更，复用已读取的远端状态。目录通知在 600 毫秒窗口内合并，根据变更文件更新对应领域；无法定位领域时刷新全部。连接、场景切换和 20 秒周期刷新全部领域，保证遗漏通知后仍可收敛。同步关闭后取消云端观察回调排队的任务和定时器。

本机播放快照独立于同步服务：播放器在暂停、定位、音频中断及切歌时保存，播放期间复用引擎计时回调每 20 秒保存；场景切换在启动云端任务前直接提交本机快照。存储层按文件合并 150 毫秒窗口内的待写快照，写入进行中只保留后续最新值；串行写入保证较早快照不会最终覆盖新状态。Mac 正常退出时通过 flush 立即落盘最新快照并等待正在执行的写入完成。关闭同步或连接失败不影响这些保存路径；系统强制终止仍可能丢失最近一次保存后的进度。

偏好按字段的逻辑修订合并，不依赖设备时间决定胜者。未知字段保留；不支持的格式版本停止应用。第一次连接先读取远端偏好，再补齐缺失项。音量、输出设备、缓存、窗口位置、平台专属布局和 AutoMix 配置留在本机。

播放会话保留原队列、实际顺序、当前位置、当前歌曲、下一首列表、来源、循环模式和进度。云端分为不可变队列快照与轻量进度文件：`Queues/<queueRevision>.json` 保存账号、去重歌曲表、原队列与实际顺序、下一首列表、来源及顺序标记；`playback.json` 保存队列修订 ID、当前歌曲、出现位置、循环模式和进度。当前歌曲独立携带元数据，支持队列外的下一首及私人 FM；队列中的同 ID 不同元数据分别保留，重复出现位置也可还原。队列内容变化时先发布新快照，再原子替换进度文件；进度或循环模式变化不会重写歌曲表。重连或重启后的首次发布会从本设备已有检查点恢复快照引用，内容相同时继续复用。恢复时引用的旧队列文件缺失，会记录日志并由校验通过的本机会话发布新快照，再替换检查点；存在但待下载或损坏的文件仍明确报错并重试。

文件可能乱序到达。接收端只读取进度明确引用的队列，并检查设备归属、修订顺序及游标范围。引用文件尚未到达或仍在下载时保留上一次完整会话，新设备则等待完整数据；下一轮继续重试，不把旧队列与新进度拼接。即使会话尚不完整，也先观察其逻辑修订，避免重装后发布旧修订。删除标记及设备记录删除会撤下旧会话。

旧队列清理在每次连接的首次播放发布后检查，此后使用单调时钟每 24 小时检查一次，复用队列的发布也可触发到期维护。清理时同时协调进度文件和队列目录，保留当前指针、未解决冲突版本引用的快照及本次连接中已知的上一份快照，仅删除超过 7 天且未被引用的 UUID 命名快照；其他设备目录、近期文件与未知文件名不参与清理。7 天是异步传输的宽限期，不是跨设备确认；长期离线设备恢复时可能暂时缺少过时指针的队列，最终依靠最新完整记录收敛。清理成功后才记录维护时间，失败呈现错误并在后续发布重试。

远端会话只展示，用户点击接续后才应用；不会远程暂停另一台设备。仅当前有效登录账号与会话所属账号一致时发布播放状态；访客和账号不匹配时撤回本设备已有记录，无记录则不写播放文件。撤回依据原始检查点判断，即使旧队列文件缺失也能完成。进度在前台或后台播放时每 20 秒发布，暂停、切歌、队列变更及场景切换也会发布；iCloud 的传输时间由系统决定。Mac 接续未缓存歌曲时先通过现有缓存下载完整文件，再从保存的位置开始。

Repository 按文件资源身份及内容代次缓存已解码记录，每次读取仍重新枚举冲突版本。不提供这些标识的文件系统通过比较实际字节判断能否复用，不依赖文件大小或修改时间。读写缓存和冲突记录统一使用解析后的文件路径作为键，写入成功后关联实际文件版本填充缓存；读取失败、删除和重新连接使缓存失效；历史队列的解码缓存不随磁盘保留期累积。自身写入通知仍参与合并，不屏蔽同设备目录中的外部变更。队列在编解码边界用单个歌曲 ID 计数表验证出现次数，歌曲表仍完整判等以保留同 ID 的元数据差异。进度与队列拼接时只检查游标，接续执行前仍校验账号和完整会话。SyncService 不再重复遍历已经校验的队列。以上缓存及文件拆分不改变本机播放快照与云端开关的独立性，本机仍保存完整会话与最近播放记录；Mac/iOS 共用本机快照格式，旧队列字段仅用于读取历史文件，不再与完整会话重复写入。

双端账号独立，仅登录同一网易云账号时展示和执行接续；未登录会话不能互相接续。执行时再次检查当前凭据与账号绑定，保留原队列来源。Mac AutoMix 的实际顺序可以在 iOS 按普通列表继续，iOS 不运行 AutoMix。

登录同步默认关闭。连接同一目录、完成本机登录检查且没有已绑定账号后，Mac 侧栏账号区域、iPhone「我的」账号区域及登录页提供「以昵称登录」，说明为「在已连接的设备间同步登录状态」。同账号的多设备记录合并展示。点击后验证凭据并保存登录，随后开启本机登录同步，将账号共享回其他设备；不会自动接续。主动退出只清除本机登录，撤回本设备记录，不请求网易云注销共享会话，也不隐藏其他设备的可用账号；其他设备保持登录，因此可以反向接收。

设置提供同步与登录同步开关；同步说明为「在设备间接续播放，同步设置」。首次开启时尝试自动容器连接或恢复书签，需要目录访问权时直接呈现系统选择器，后续自动恢复。设置不展示目录或更改入口，授权失效后提供「重新连接」。Mac 保留播放列表接续入口；iPhone 各播放布局的队列均提供接续，本机尚未播放时可从顶部接续提示进入。接续行显示设备与歌曲，移除容易被误认为歌曲进度的记录更新时间计数。

同步目录访问权是登录凭据的信任边界。登录文件不再额外加密，具有目录读取权的人或应用可以取得凭据；目录不应共享或公开。设置保留「仅连接你信任的同步位置」说明。iCloud 自身提供的保护取决于用户配置，应用不承诺独立的端到端加密。接收端通过不落盘的独立客户端验证网易云登录态，验证成功、本机账号未变化且目录授权仍有效时才保存。凭据持久化失败保留原登录态。单个设备的登录文件下载、解码或校验失败会记录不含凭据的诊断日志并跳过该设备，后续同步重试；其他有效账号仍可展示。目录整体不可读则通过同步错误状态提示。最新记录无效时不重新提供该设备的旧登录，自己的有效登录记录缺失时会重新发布。退出或关闭登录同步为本设备发布删除标记。普通同步关闭保留云端文件；不提供跨设备强制退出或实时控制。

同步仅订阅切歌、播放状态、队列及循环、可同步偏好及账号检查等离散事件，进度通过既有的 20 秒周期保存。收藏、歌单加载和本机专属设置不触发同步。设备身份成功读取后在进程内缓存；错误不缓存。开启同步仅在缺少目录授权时要求选择目录，系统错误直接呈现，失效请求按取消处理。登录、退出和接续操作通过抛出错误交由界面呈现。登录验证跨越网络请求，提交前仍复核同步授权和本机认证代次，防止已经退出或切换目录的请求写入账号。

当前功能尚处于本地开发阶段，只维护当前格式，不迁移旧配对记录、旧安装 ID 或旧版播放快照。已有开发目录需要在两端关闭同步后清理旧测试数据，再用当前版本重新连接；否则旧版播放快照或加密 `login.json` 会明确报错，旧安装目录也可能继续作为远端设备展示。本机播放快照也使用当前歌曲表格式，旧开发快照不兼容。清理云端目录会丢弃其中的测试快照及共享登录凭据，本机账号独立保留。

具有相同 iCloud 容器权限的构建可以自动连接容器；当前 iOS entitlement 未配置该权限。要覆盖不同团队重签名的侧载版，首次系统目录授权仍需保留，随后通过书签恢复。自动容器与手选目录需指向同一 repository 才能互通，不能假定应用私有容器等同于 iCloud 云盘中的任意目录。

## 验证边界

自动化测试覆盖逐字段冲突收敛、重复歌曲位置、同账号及未登录接续边界、设备身份持久化与并发创建、重装后排除本机记录及同名设备区分、身份读取失败停止发布、单一登录文件、重复账号与删除标记、本机退出后从另一设备记录重新接收、授权连接隔离、目录重命名、版本拒绝，以及登录和退出时凭据写入失败保留原登录态。Mac/iOS 构建不证明真实 iCloud 或网易云跨设备会话可用。

收敛验证还覆盖关闭同步后的偏好事件、过时连接取消、偏好或播放损坏时登录撤回与其他领域传播、失败领域修复后的重试，以及歌曲表的重复位置、同 ID 元数据差异、队列外歌曲与无效引用拒绝。

播放 Repository 测试覆盖未变化文件只解码一次、同大小同时间戳下的原子替换及原位修改、损坏文件缓存失效、删除/重连、进度及循环模式更新不重写队列、重连及模拟重启后复用快照、两种文件到达顺序、缺失快照保留完整会话、设备归属及游标校验、删除标记，以及过期队列清理范围和维护周期。真实 iCloud 冲突版本的生成与传播仍需双端验证。

发布前需在 Mac 与重签名 iOS 真机验证：同一 iCloud 目录双向传播；重启后书签访问；离线修改后合并；点击接续及连续切歌；不同网易云账号；凭据过期；目录撤权/删除；iCloud 账号切换。无 entitlement 的版本可能无法提供 iCloud 身份 token，账号切换还依赖 File Provider 撤销旧目录授权，必须真机验证。
